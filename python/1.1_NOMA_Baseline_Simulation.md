# Mô phỏng Baseline cho Hệ thống NOMA (Không có AN hoặc DPC)

## Mục tiêu

- Xây dựng mô hình NOMA cơ bản để đánh giá hiệu năng hệ thống trong điều
  kiện không áp dụng giải pháp bảo mật (Artificial Noise - AN hoặc Dirty
  Paper Coding - DPC).
- Đo lường các thông số như tổng dung lượng kênh (sum rate), tỷ lệ lỗi
  bit (BER), hoặc xác suất chặn (outage probability) trong môi trường có
  người nghe lén.

## Mô hình hệ thống

- **Cấu hình**:
  - Một trạm gốc (BS) phục vụ nhiều người dùng (UE) trên cùng tài nguyên
    tần số/thời gian.
  - Phân bổ công suất khác nhau dựa trên điều kiện kênh (người dùng gần
    BS có công suất thấp hơn, người dùng xa có công suất cao hơn).
  - Kênh truyền: Kênh fading Rayleigh với nhiễu Gaussian trắng (AWGN).
  - Người nghe lén: Có một thiết bị cố gắng giải mã tín hiệu từ BS.
- **Thông số**:
  - Số người dùng: $N = 2$.
  - Công suất truyền tổng: $P_{\text{total}} = 1$ (chuẩn hóa).
  - Hệ số phân bổ công suất: $\alpha = [0.8, 0.2]$.
  - Công suất nhiễu: $\sigma^2 = 0.01$.
  - Số lần mô phỏng Monte Carlo: $10^4$.
  - Dải SNR: $0$ đến $20$ dB.

## Mô hình toán học

- **Tín hiệu truyền**:
  $$x = \sqrt{P_{\text{total}}} \sum_{i=1}^N \sqrt{\alpha_i} s_i$$ Với
  $s_i$: tín hiệu của người dùng $i$.

- **Tín hiệu nhận tại người dùng $i$**: $$y_i = h_i x + n_i$$ Với $n_i$:
  nhiễu AWGN, công suất $\sigma^2$.

- **Tín hiệu tại người nghe lén**: $$y_e = h_e x + n_e$$

- **Dung lượng kênh**:

  - Người dùng $i$:
    $$R_i = \log_2\left(1 + \frac{|h_i|^2 \alpha_i P_{\text{total}}}{\sum_{j<i} |h_i|^2 \alpha_j P_{\text{total}} + \sigma^2}\right)$$
  - Người nghe lén:
    $$R_e = \log_2\left(1 + \frac{|h_e|^2 \alpha_i P_{\text{total}}}{\sum_{j<i} |h_e|^2 \alpha_j P_{\text{total}} + \sigma^2}\right)$$

## Mã MATLAB

``` matlab
% Khởi tạo thông số
N = 2; % Số lượng người dùng
P_total = 1; % Công suất tổng
alpha = [0.8, 0.2]; % Hệ số phân bổ công suất
sigma2 = 0.01; % Công suất nhiễu
num_sim = 1e4; % Số lần mô phỏng
SNR_dB = 0:2:20; % Dải SNR

% Tạo kênh fading Rayleigh
h = (randn(N, num_sim) + 1i*randn(N, num_sim))/sqrt(2); % Kênh hợp lệ
h_e = (randn(1, num_sim) + 1i*randn(1, num_sim))/sqrt(2); % Kênh nghe lén

% Tính dung lượng
R = zeros(N, length(SNR_dB)); % Dung lượng người dùng
R_e = zeros(N, length(SNR_dB)); % Dung lượng người nghe lén
for snr_idx = 1:length(SNR_dB)
    SNR = 10^(SNR_dB(snr_idx)/10);
    for sim = 1:num_sim
        % Tín hiệu nhận tại người dùng
        for i = 1:N
            interference = sum(abs(h(i, sim)).^2 * alpha(1:i-1) * P_total);
            SINR_i = abs(h(i, sim)).^2 * alpha(i) * P_total / (interference + sigma2);
            R(i, snr_idx) = R(i, snr_idx) + log2(1 + SINR_i);
        end
        % Tín hiệu nhận tại người nghe lén
        for i = 1:N
            interference_e = sum(abs(h_e(sim)).^2 * alpha(1:i-1) * P_total);
            SINR_e = abs(h_e(sim)).^2 * alpha(i) * P_total / (interference_e + sigma2);
            R_e(i, snr_idx) = R_e(i, snr_idx) + log2(1 + SINR_e);
        end
    end
    R(:, snr_idx) = R(:, snr_idx) / num_sim;
    R_e(:, snr_idx) = R_e(:, snr_idx) / num_sim;
end

% Trực quan hóa
figure;
plot(SNR_dB, R(1,:), 'b-', 'LineWidth', 2, 'DisplayName', 'User 1');
hold on;
plot(SNR_dB, R(2,:), 'r-', 'LineWidth', 2, 'DisplayName', 'User 2');
plot(SNR_dB, R_e(1,:), 'b--', 'LineWidth', 2, 'DisplayName', 'Eavesdropper (User 1)');
plot(SNR_dB, R_e(2,:), 'r--', 'LineWidth', 2, 'DisplayName', 'Eavesdropper (User 2)');
xlabel('SNR (dB)');
ylabel('Rate (bps/Hz)');
legend('show');
title('Sum Rate vs SNR for NOMA Baseline');
grid on;
```

## Phân tích dữ liệu

- **Dung lượng kênh**:
  - So sánh dung lượng của người dùng hợp lệ và người nghe lén theo SNR.
  - Tính **secrecy rate**: $$R_s(i) = \max(0, R_i - R_e(i))$$
- **Xác suất chặn** (nếu cần):
  $$  P_{\text{out}} = P(R_i < R_{\text{th}})
    $$
- Lưu kết quả vào file `.mat` để so sánh với các giải pháp bảo mật sau
  này.
